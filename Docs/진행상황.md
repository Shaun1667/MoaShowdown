## 2. 새 PC에서 처음 할 일

1. 저장소 받기
   ```bash
   git clone https://github.com/Shaun1667/MoaShowdown.git
   ```
2. main 그대로 쓰면 됨 (O-3까지 들어 있음).
3. Unity Hub → Add → `MoaShowdown` 폴더 → **Unity 6000.3.25f1**로 열기 (버전 바꾸지 않음 — 다른 버전으로 열면 버전 파일 · 패키지 · URP 설정이 바뀜).
4. 처음 열 때 패키지 · 라이브러리를 새로 만든다 (UGS · Netcode 패키지 때문에 몇 분 더 걸림). 콘솔 오류 0인지 확인.
5. **UGS 연결**: Edit → Project Settings → Services에서 같은 클라우드 프로젝트(`041f6f3e-…`, 조직 goni0309, 이름 "My project 2026-11-06_09-39-30")에 연결돼 있는지 확인. 안 되어 있으면 온라인 방이 안 만들어짐.
6. Unity MCP(Claude가 에디터를 다루는 연결) 다시 연결 — Unity AI Assistant 패키지(`com.unity.ai.assistant`)가 들어 있음.
7. Window → General → Test Runner → EditMode → Run All → **247개** 확인 (실패가 있으면 이름 · 메시지를 Claude에게).
8. `Scenes/Battle.unity` 열고 플레이 → GameRoot `Mode` = Lobby면 1라운드 캐러셀부터(오프라인), Online이면 온라인 대기실부터.

주의
- `ProjectSettings/ProjectSettings.asset`의 `APP_UI_EDITOR_ONLY` 한 줄 · `Assets/Settings/Mobile_RPAsset.asset`의 버전 변경은 Unity가 자동으로 넣는 것 — **항상 커밋에서 뺀다**.
- 저장 위치는 `AppData/LocalLow/NariGames/MoaShowdown` (PC마다 따로, 저장소에 없음). 온라인 전투 결과 다름 기록은 그 아래 `OnlineLogs/mismatch.log`.
- 확인 · 시험으로 플레이할 때 GameRoot `Mode` · `runSeed` · `localWriteFolder`를 바꿨다면 끝나고 되돌린다 (씬은 `Mode` = Lobby, `runSeed` = 0, `localWriteFolder` = LocalOpponents로 저장돼 있음).
- 셸에 Python 없음 → 스크립트는 PowerShell / bash.

## 5. 임시값 · 알려진 문제 (잊지 말 것)

- **온라인은 2명 이상으로 한 번도 확인 안 함** (O-1 · O-2 · O-3 모두 방장 혼자 + 봇으로만, 방장 넘기기 · 나감 · 다름 보고는 시뮬레이션 · 테스트 코드로만).
- 몬스터 20종의 이름 · 수치 · 등급 확률표는 임시 (체감 밸런스 확인 전, BALANCE 7 · 12 · 17). PvE 20R 팀은 검증 못 함 (BALANCE 16).
- 봇 AI는 능력을 보지 않고 초당 피해만 보고 산다 — 새 효과(이웃 · 골드)를 잘 못 씀.
- 온라인 실패 문구가 UGS 영어 원문 그대로.
- 온라인 넘김 데이터는 작은 표시뿐 — 새 방장은 자기가 받아 둔 마지막 상태를 씀 (넘기기 직전 몇 초 변화는 빠질 수 있음).
- 플레이 모드가 "저절로 꺼지는" 건 MCP 확인 스크립트 컴파일 때문 (CLAUDE 코딩 규칙). 사람이 직접 플레이할 때는 상관없음. **플레이 중에 스크립트를 고치지 않는다**.
- 판매가 75%는 추정 · 목숨 잃는 수 구간은 임시 (BALANCE 5 · 10).
- 글꼴은 내장 `LegacyRuntime.ttf` (Windows 한글 대체 글꼴로 보임) → 다른 OS · 빌드 전에 한글 글꼴 에셋 필요.
- 에디터 창이 포커스가 없으면 스크립트를 다시 컴파일하지 않음 → 에디터를 한 번 눌러 주거나 Claude가 `AssetDatabase.Refresh` 호출.
