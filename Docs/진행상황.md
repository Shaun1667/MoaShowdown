## 2. 새 PC에서 처음 할 일

1. 저장소 받기
   ```bash
   git clone https://github.com/Shaun1667/MoaShowdown.git
   ```
2. L-5 작업 브랜치로 가기 (main에는 아직 L-5가 없음)
   ```bash
   git switch phase-l5-lobby-view
   ```
3. Unity Hub → Add → `MoaShowdown` 폴더 → **Unity 6000.3.25f1**로 열기 (버전 바꾸지 않음). 이전 `My project` 경로 항목이 있으면 Hub에서 삭제.
4. 처음 열 때 패키지 · 라이브러리를 새로 만든다 (몇 분). 콘솔 오류 0인지 확인.
5. Unity MCP(Claude가 에디터를 다루는 연결) 다시 연결 — Unity AI Assistant 패키지(`com.unity.ai.assistant`)가 들어 있음.
6. Window → General → Test Runner → EditMode → Run All → **169개 통과** 확인 → Claude에게 "다 통과했어 main에 병합하고 푸시해줘".
7. `Scenes/Battle.unity` 열고 플레이 → 1라운드 캐러셀부터 시작하면 정상.

주의
- `ProjectSettings/ProjectSettings.asset`의 `APP_UI_EDITOR_ONLY` 한 줄은 Unity AI 패키지가 자동으로 넣는 것 — **항상 커밋에서 뺀다**. 새 PC에서도 생기면 그대로 두고 커밋만 안 함.
- 저장 위치는 `AppData/LocalLow/NariGames/MoaShowdown` (PC마다 따로, 저장소에 없음). 로비 모드는 내 팀을 저장하지 않음.
- 확인 · 시험으로 플레이할 때 GameRoot `localWriteFolder`를 `LocalOpponents_ClaudeCheck`로 바꿨다가 끝나면 되돌리고 그 폴더만 지운다. 씬 `runSeed`는 확인 후 0으로 되돌린다.
- 셸에 Python 없음 → 스크립트는 PowerShell / bash.

## 5. 임시값 · 알려진 문제 (잊지 말 것)

- **일반 풀 60은 임시** (TFT 값 29) — 몬스터가 6종뿐이라 풀이 바닥나서 늘림. 몬스터 종류가 늘면 29로 (BALANCE 14).
- **PvE 팀이 너무 약함** — 봇이 PvE를 전부 이김 (몬스터 6종 · 일반뿐이라 8R에 이미 Lv2~3 6마리). 몬스터가 늘면 다시 맞춤 (BALANCE 16).
- 판매가 75%는 추정 · 목숨 잃는 수 구간은 임시 (BALANCE 5 · 10).
- 글꼴은 내장 `LegacyRuntime.ttf` (Windows 한글 대체 글꼴로 보임) → 다른 OS · 빌드 전에 한글 글꼴 에셋 필요.
- 플레이 모드가 가끔 저절로 꺼짐 (원인 모름, 콘솔 오류 없음) — 다시 들어가면 됨.
- 에디터 창이 포커스가 없으면 스크립트를 다시 컴파일하지 않음 → 에디터를 한 번 눌러 주거나 Claude가 `AssetDatabase.Refresh` 호출.
