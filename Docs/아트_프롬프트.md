# 몬스터 3D 모델 만들기 (Phase G) — 2026-11-09

결정 (2026-11-09, 사용자): 톤 = **귀여운 카툰 로우폴리**, 만드는 법 = **외부 AI 도구(Varco 3D 등) → 가져오기 자동화**, 움직임 = **코드 연출만**(뼈대 · 애니메이션 없음).
참고 게임의 캐릭터 · 아트 · 이름을 가져오지 않는다 (CLAUDE 아트 규칙). 기존 캐릭터와 닮았으면 다시 만든다.

## 1. 만드는 순서

1. AI 도구에 아래 **공통 문구 + 몬스터 한 줄**을 넣어 만든다 (이미지 → 3D면 먼저 이미지를 만들고 3D로).
2. **FBX**로 내려받는다 (텍스처 포함). GLB는 아직 못 읽음 — 꼭 필요하면 Claude에게 glTFast 패키지 추가를 부탁.
3. 파일 이름을 **몬스터 ID**로 바꿔 `Assets/_Project/Art/<도구 이름>/`에 넣는다. 예: `Art/Varco/ember.fbx`
   (텍스처 파일이 따로 오면 같은 폴더에)
4. Unity 메뉴 **MoaShowdown → Setup → Monster Visuals** → 콘솔에 "모델 연결 N종".
   - 높이(0.9) · 바닥을 자동으로 맞춘 프리팹이 `Art/Prefabs/Monsters/<ID>.prefab`에 생긴다.
   - 이름이 안 맞는 파일 · 모델이 없는 몬스터는 콘솔에 목록으로 나온다 (모델이 없으면 캡슐로 그림).
5. 플레이해서 본다. 방향 · 크기 · 높이가 이상하면 `Data/MonsterVisuals.asset`의 그 줄에서 `yaw`(방향, 도) · `scale` · `yOffset`만 고친다 (Setup을 다시 돌려도 보정 값은 그대로).
   - 몬스터 앞쪽이 +Z(Unity 앞)라고 가정한다. 옆이나 뒤를 보면 `yaw`에 90 · 180 · −90.

### 1-1. Claude가 Varco 커넥터로 만들 때 (2026-11-09 G-1에서 쓴 방법)

- Varco 플로우 **"MoaShowdown"**(id `ebfc4cb1-…`)에 몬스터마다 한 줄: `TextInput`(공통 문구가 들어간 프롬프트) → `GenerateImage`(1:1) → `Generate3D`(폴리곤 8,000 · tri · 텍스처 2048 · PBR 0 · tPose 0 · 비공개 라이선스).
- **이미지만 먼저 돌려** 사용자가 Varco 편집 화면에서 확인 → "3D 진행" → 3D를 돌린다 (포인트 절약).
- 포인트 (2026-11-09 CREATOR 등급 기준 실제): 이미지 1장 **50**, 3D 1개 **200** → 몬스터 1종 약 250.
- 받기: `get_output_downloads(exportType: fbx, pivotToBottom: true)` → `Art/Varco/<ID>.fbx`.
- Varco FBX는 텍스처를 품고 있지만 재질이 가리키지 않는다 → Setup/Monster Visuals가 꺼내서 재질을 만든다 (따로 할 일 없음).
